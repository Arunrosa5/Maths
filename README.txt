ANDROID INSTALLATION
1. Extract this ZIP on a computer.
2. Publish the complete folder to an HTTPS static host (for example GitHub Pages or Netlify).
3. Open the HTTPS website address in Chrome on your Android phone.
4. Tap Chrome menu (⋮) > Install app or Add to Home screen.
5. Open CSIR Maths Study from your home screen.

This is a Progressive Web App, not a Play Store APK. HTTPS hosting is required for installation/offline caching. ChatGPT opens separately and may require sign-in. Checklist and score are stored only in this browser on this phone; they do not sync automatically. Verify your official exam date and shift on your admit card.
